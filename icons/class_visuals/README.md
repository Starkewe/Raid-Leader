# Class visual assets

The twenty PNGs in this directory are the supplied 128×128 class-icon masters. They
are intentionally kept as complete opaque tiles; the raid frame does not chroma-key,
recolor, or split them apart.

The `compact` directory contains deterministic 16×16 derivatives for the command
reference browser. The raid frame uses the masters and scales them to its approximately
44×44 class tile.
